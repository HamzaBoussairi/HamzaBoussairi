### What I work on

- **Analytics engineering** — ELT pipelines (Meltano, Singer taps), dbt models, Kimball star schemas, data quality
- **BI & dashboards** — Superset and Power BI on top of clean warehouse layers
- **Applied AI** — LLM apps, RAG, agents with LangChain / LangGraph, speech-to-text, document summarization
- **AI in sensitive domains** — de-identification, human-in-the-loop validation, traceable generation
